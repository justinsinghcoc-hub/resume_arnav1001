# Arnav Singh’s Resume

A static HTML resume hosted on Netlify. The homepage is `index.html`; no dependencies or build command are required.

For a local preview, run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

Netlify publishes the repository root using `netlify.toml`. The original `/index12.html` URL redirects to the homepage.
